# Samir Fit — Telegram Mini App

Фитнес-тренер в Telegram: тренировки, направления Калистеника / CrossFit / Hybrid, питание, кольца активности, прогресс.
Подписка — звёздами Telegram, 30 дней бесплатно для новых пользователей.

## Файлы

```
index.html              — точка входа
css/style.css           — дизайн
js/config.js            — ⚙️ НАСТРОЙКИ ПРИЛОЖЕНИЯ (счётчик пользователей, ники тренера и разработчика)
js/exercises.js         — 80+ упражнений и анимированные фигуры
js/data.js              — базовые программы, план недели, база продуктов, достижения
js/storage.js           — хранение данных пользователя (Telegram CloudStorage)
js/access.js            — пробный период, подписка, оплата звёздами
js/app.js               — логика приложения
api/me.js               — проверка доступа пользователя
api/invoice.js          — счёт на оплату звёздами
api/bot.js              — бот: оплата, команды администратора
api/cron.js             — ежедневные напоминания об окончании доступа
api/setup.js            — одноразовая настройка бота
api/_lib/settings.js    — ⚙️ НАСТРОЙКИ БОТА (цена, пробный период, администратор, выключатель оплаты)
api/_lib/programs.js    — платные программы: Калистеника, CrossFit, Hybrid (4 уровня, 49 тренировок)
vercel.json             — расписание напоминаний
```

## Запуск (один раз, ~15 минут)

1. **Загрузите все файлы в GitHub**, сохранив папки (`api`, `api/_lib`, `css`, `js`). Vercel сам опубликует сайт.
2. **База данных.** Vercel → ваш проект → вкладка **Storage** → **Create Database** → **Upstash for Redis** (бесплатный план) → **Connect** к этому проекту. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` добавятся сами.
3. **Секреты.** Vercel → **Settings → Environment Variables**, добавьте две переменные:
   - `BOT_TOKEN` — токен бота из @BotFather (выглядит как `123456789:AA...`). Никому его не показывайте.
   - `CRON_SECRET` — любая длинная строка **только из латинских букв и цифр**, например `SamirFit2026secretKey`.
4. **Перезапустите сайт:** Vercel → **Deployments** → у последнего «⋯» → **Redeploy**.
5. **Настройте бота:** откройте в браузере `https://ВАШ-ДОМЕН.vercel.app/api/setup?key=ВАШ_CRON_SECRET`. Должно появиться «✅ Бот настроен».
6. **Станьте администратором:** напишите боту `/start` со своего аккаунта @sahatmuradov, потом `/help`.

Готово. Платёжный провайдер для звёзд не нужен — оплата идёт напрямую через Telegram.

## Команды администратора (только для @sahatmuradov)

| Команда | Что делает |
|---|---|
| `/give @ник 30` | выдать или продлить доступ на N дней (остаток не сгорает) |
| `/revoke @ник` | закрыть доступ и отменить автопродление |
| `/info @ник` | статус, дата окончания, автопродление, число оплат |
| `/list` | все активные подписчики |
| `/refund @ник` | вернуть звёзды за последнюю оплату и закрыть доступ |
| `/stats` | всего пользователей, подписчиков, на пробном периоде |

Вместо @ника можно писать числовой id. Человек должен хотя бы раз открыть приложение или бота.
Каждая оплата и продление приходят вам сообщением в бота.

## Как это работает для клиента

1. Первый вход → 30 дней всех функций бесплатно, сразу показывается экран «это пробный период».
2. Бот напоминает за 3 дня и за 1 день до окончания, и в день окончания.
3. После окончания закрыты тренировки, питание и активность. Прогресс, вода, вес и профиль доступны всегда.
4. Оплата — 219 ⭐, автопродление каждые 30 дней. Если оплатить во время пробного периода, бесплатные дни сохраняются.
5. Отменить автопродление клиент может в Настройках Telegram → Мои звёзды. Вопросы — команда `/paysupport`.

## Частые настройки

- **Скрыть счётчик «Нас уже N»:** `js/config.js` → `SHOW_USER_COUNTER: false`
- **Цена / пробный период:** `api/_lib/settings.js` → `PRICE_STARS`, `TRIAL_DAYS`
- **Сделать всё бесплатным (аварийно):** `api/_lib/settings.js` → `PAYWALL: false`
- **Время напоминаний:** `vercel.json` → `"0 7 * * *"` = 07:00 UTC = 12:00 по Ташкенту/Ашхабаду
