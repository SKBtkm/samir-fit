# Samir Fit — Telegram Mini App

Фитнес-тренер в Telegram: тренировки, питание, калории, кольца активности, прогресс.

Это статический сайт, сборка не нужна. Загрузите файлы в GitHub и подключите к Vercel.

```
index.html        — точка входа
css/style.css     — дизайн (чёрно-красная тема)
js/exercises.js   — 42 упражнения и анимированные фигуры
js/data.js        — программы, план недели, база продуктов (~130 блюд), достижения
js/storage.js     — хранение: Telegram CloudStorage + localStorage
js/app.js         — логика приложения
```
